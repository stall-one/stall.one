Agents

Agents take the busywork off small sellers — better copy, better photos, channel-ready fields — then hand a supervised path into the marketplace browser UI. Not a channel API integration product. Not “advanced” ops tooling.

Project
Listia
Type
Field note · draft
Audience
Builders · operators
AGENTS SMALL_SELLER MULTIMODAL HITL

Product wedge

Listia is for sellers who are not ready for marketplace developer programs, inventory sync platforms, or multi-channel ERPs. They retype listings by hand today. Agents remove that grind without requiring them to become integrators.

Agent map

  • Metadata enrichment — saved product → SEO / channel-shaped copy, tags, text embeddings in aiContext (async; never block save).
  • Photo enrichment — source photo + prompt → new studio / lifestyle / social assets; confirm before gallery attach.
  • Vision / attributes — image → structured fields for the listing draft.
  • Schema mapper — base product + overrides → per-channel listing shape (eBay / Amazon / Etsy forms of truth, not their public seller APIs).
  • Adapter agent — hands payload to browser execution so the listing is entered the way the seller already works: in the channel UI.

Swarm sketch

                 ┌─ metadata worker ──► aiContext (copy · tags)
Product save ────┤
                 └─ events ───────────► (later: search / facets)

Source photo ──► gen AI ──► vision QC ──► confirm ──► media gallery

Listing intent ──► schema map ──► browser DOM adapter ──► human gate ──► channel UI
                                   (not marketplace seller APIs)

Boundaries

  • Human core fields — seller-owned title/SKU not silently overwritten
  • aiContext — candidates only until confirm
  • No channel API as the product path — publish path is browser execution
  • Publish stays gated — agents do not auto-click live on reputation-sensitive actions
  • Outgrow path — when a seller needs full API sync and warehouse tooling, Listia is not that product

Visibility

Small sellers still need to trust the system. Runs should show what each agent proposed, what was accepted, and where browser steps stopped — not “it just listed it.”

What stuck

Split agents, isolated AI storage, short seller paths, and a hard publish gate. The swarm replaces copy-paste across marketplaces — not the need for a more advanced API-based stack later.

Open questions (draft)

  • How much agent UI a solo seller tolerates before it feels like “advanced software.”
  • Default models and cost caps per small-org plan.
  • Messaging when someone should graduate off Listia to channel APIs / sync tools.
