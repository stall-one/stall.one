Isolation model

Every query path carries a tenant id derived from the session, never from the client body alone. Vector stores, object keys, and job queues are namespaced. Cross-tenant joins are structurally impossible in the query layer, not merely forbidden in app code.

Storage split

JuiceFS holds immutable document blobs. Turso/SQLite holds tenant metadata, classification labels, and embedding references. Large files stay on a filesystem contract; hot metadata stays portable.

Ingest → classify → retrieve

  • Upload lands in a tenant vault.
  • Workers run Docling prep and model classification.
  • Embeddings write under the same tenant scope.
  • Retrieval always filters by policy before ranking.

Desktop pairing

Firms often need documents on machines they control. Pairing establishes a short-lived, device-bound session that mounts the vault workflow without emailing PDFs.

Outcome

Isolation is a first-class product constraint — not a bolt-on filter. The hub case study covers business narrative; this page is the system design layer.
