Aesthetic pivot

Consumer banks use teal trust. Degens expect neon. We use restrained neon gradients on near-black so it feels capable, not casino — and keep the actual signing ceremony plain.

Ceremony design

One primary button: unlock with passkey. No seed grid. Advanced chains live behind progressive disclosure.

Error copy

Failed UV and missing PRF get plain explanations, not scary red walls of text.

Personas / workflow

Mobile user

Biometrics only; hates seed phrases.

Power user

Wants multi-chain and export policies.

Security reviewer

Wants threat model and storage claims.

Product maturity signal

Design choices here are deliberate pivots with psychological and workflow reasoning — not whatever looked cool that day.
