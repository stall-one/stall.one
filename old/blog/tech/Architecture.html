Command Streaming Architecture

Server simulation, command deltas, client GPU execution, and where asset streaming still belongs.

WHITE_PAPER SYSTEM_DESIGN GRAPHICS COMMAND STREAMING
Server sim ──► command delta encode ──► network │ ▼ client command decode │ ▼ local GPU (full fidelity path) Asset CDN ──► meshes/textures ──► client cache (separate plane)

Two planes

Command/API streaming and asset/data streaming solve different bottlenecks. Treating one as a subtype of the other confuses protocol design.

Delta + prediction

Only ship state transitions; predict short-term client-side to hide RTT.

Authority

Server remains authoritative for competitive sim; client is renderer + predictor, not cheat surface.

When video still wins

Untrusted clients, unknown GPUs, or pixel-perfect legal capture may still require video — choose deliberately.
