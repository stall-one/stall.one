[RESEARCH: COMMAND STREAMING]

Client-side GPU rendering for cloud gaming and remote viz — stream commands or assets, not pixels. Taxonomy of command/API vs asset/data streaming with AI predictive deltas.

Role
Graphics systems research
Stack
GPU commands · Deltas · Client render
Domain
Cloud gaming / remote render
Status
Architecture research
COMMAND_STREAM ASSET_STREAM LOW_BANDWIDTH AI_PREDICT

Problem

Video cloud gaming is bandwidth-hungry, encoder-capped, and latency-sensitive. Shipping finished frames fights network physics and wastes client GPUs.

Approach

  • Separate intelligence (server sim/AI) from pixels (client GPU).
  • Command/API streaming for precise remote pipeline control.
  • Asset/data streaming for practical engine-driven client render with LOD.
  • Optimize with delta encoding, deduplication, and predictive deltas from world models / agent memory.
Outcome

A clear taxonomy and vision: often 75–95% bandwidth reduction vs video, better responsiveness, scales to multi-agent living worlds.

What shipped / built

Command streaming manifesto + asset-vs-command taxonomy log; ties to spatial/R3F performance work.
