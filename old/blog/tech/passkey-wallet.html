[WALLET: PASSKEY STATELESS]

Identity-first wallet design: biometric passkeys as the ceremony, ephemeral keys as the material, and no seed phrase sitting in IndexedDB waiting to be stolen.

Role
Security engineer
Stack
WebAuthn · HKDF
Domain
Wallets / identity
Live
Demo
WEBAUTHN STATELESS ACCOUNT_ABSTRACTION

Problem

Seed phrases punish users and concentrate risk. Server custody re-centralizes the honeypot. A modern wallet needs strong user verification without inventing yet another recovery cult.

Approach

  • WebAuthn/passkeys for presence + UV; PRF extension as a high-entropy root when available.
  • HKDF domain separation for per-chain keys (EVM, Solana, …) from a single ceremony.
  • Local-first reconstruction of session context — minimize durable secrets on disk.
  • Account abstraction-friendly flows so UX can hide raw key mechanics.
Outcome

A specialist security piece that demonstrates biometric unlock, reduced attack surface, and a path to multi-chain signing without traditional seed storage. See the technical log for PRF + HKDF detail.
