Field notes from americamattercorp/cnc-metal — a self-contained portfolio package for precision metal supply: catalog, product plate, Forge cutter, and shop guides under one print-industrial system.

4140 StockCatalogForgeGuides

04 What it is

A standalone static package for the original product idea: precision metal for CNC shops— not the services “reindustrialize” landing. Open index.html, walk catalog → product → forge → guides.

Tagline stays transactional: metal, mill finish, cut-to-order. Specs before slogans.

05 Portfolio arc

  • Brand home — what we sell (metal, not manifesto)
  • Catalog — categories and SKUs
  • Product — size, price, 3D stock preview
  • Forge — plan cut / nest / kerf before buy
  • Guides — shop literacy for the floor

06 Package map

// americamattercorp/cnc-metal/
index.html       # home · stock story · paths
catalog.html     # alloy plate · mill finish · SKUs
product.html     # 4140 billet/bar + 3D viewer
forge.html       # 3D block cutter · kerf · nesting
guides.html      # newsstand / field notes
style.css        # all tokens + chrome
images/          # blocks · plate · guide art

07 Print rules

  • Headers: bold all-caps sans (Oswald)
  • Body: serif or Work Sans — squared, balanced
  • Data: Space Mono
  • Flat UI — no soft shadows, hard borders
  • Vermilion only for danger / material finish

08 Tokens

Strict limited palette

Design bias

CNC buyers read catalogs like purchase orders. The UI stays print-flat and order-clear: hard ink borders, navy as primary, vermilion reserved for alarms and material cues. The Forge is allowed to be interactive; the chrome is not allowed to be decorative.

Takeaway

cnc-metal is the original product surface: supply CNC-ready stock with honest specs and tools to plan the cut before the spindle turns. Independent of the root services landing—same Amerimatter ink, different job: sell metal, teach the floor, nest the billet.

Run locally: cd cnc-metal && python3 -m http.server 8765
