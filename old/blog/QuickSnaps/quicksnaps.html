Snap. Describe. List.

Notes from quicksnaps — an agentic product catalog that turns raw photos into marketplace-ready copy, logistics guesses, and DOM-driven import/export without waiting on every platform’s API.

Multimodal AIDOM InjectionClayUIeBay · Mercari · Shopify

01 · What it is

QuickSnaps is a listing co-pilot for multi-channel sellers. Capture (or import) a product, run a generation pipeline, then push channel-shaped titles, tags, and specifics into the places you already sell.

The UI lives in ClayUI — soft clay surfaces, Nunito, indigo primary — because operators spend hours in this surface. Hard chrome was the wrong vibe.

02 · Why it exists

Marketplace APIs are incomplete, rate-limited, or missing. Listing still starts with a phone photo and ends in manual taxonomy work. Agents need tool paths that work against real browser UIs, not only happy-path SDKs.

QuickSnaps splits the job: vision → structured catalog item, then adapters per marketplace, then optional extension autofill.

03 · Pipeline

Category detection seeds weight/size/ship-tier assumptions (electronics vs apparel vs kitchen) so sellers are not typing box dimensions from memory every time.

04 · Marketplace adapters

Mercari

Hashtags, friendly tone, short-form description structure.

eBay

Item specifics, weight parameters, return policy scaffolding.

Shopify

05 · Import & export

  • Import — scrape a live marketplace tab into the catalog
  • Export — autofill a blank listing form from a saved item
  • No API keys required for the DOM path
  • Human review before irreversible publish

06 · ClayUI contract

Design system tokens: soft dual shadows (out / in), large radii (12 / 20 / 32), primary indigo #6366F1, secondary pink, body #f0f4f8.

Buttons scale on press into inset clay shadows — tactile feedback for high-frequency listing actions.

Design bias

The bottleneck in multi-channel selling is not “generate a caption.” It is consistent structure across markets, logistics fields you can ship against, and a path to the live UI when APIs refuse to cooperate — with a human still in the loop.

Takeaway

QuickSnaps is the agentic e-commerce slice of the portfolio: multimodal ingestion, per-market copy contracts, logistics heuristics, and extension-shaped tool use. Soft clay UI keeps long sessions usable; the hard problem stays in the adapters and the review step.
