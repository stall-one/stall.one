Shell vs payload

The facility shell owns power, climate bus, drainage, and networking. Modules (hydro, myco, protein) are payloads with a standard mechanical/electrical contract. You expand by snapping modules, not redesigning buildings.

Sensing fabric

Cheap continuous probes on every tray; higher-cost multi-modal scanners on a shared schedule. RF/mmWave and HSI catch stress and pests before visual inspection does.

Control loop

Raspberry Pi class edge brain runs local automation with cloud optional for fleets. Fail-safe: climate and irrigation degrade gracefully if uplink dies.

Roadmap layers

Phase 1 hydro food. Phase 2 materials (mycelium). Phase 3 microbial protein. Same shell, different payloads and SOPs.
